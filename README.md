# Планировщик задач (TODO App)

Веб-приложение для управления личными задачами. Проект разработан в качестве итоговой дипломной работы. Серверная часть написана на языке Go, данные хранятся в локальной базе данных SQLite. Фронтенд предоставляется в готовом виде и общается с сервером через REST API.

## Выполненные задачи и функционал

Реализован базовый функционал планировщика:
* **Добавление задач:** с указанием заголовка, комментария, даты и правила повторения.
* **Редактирование задач:** изменение любых параметров существующей задачи.
* **Удаление и выполнение:** отметка одноразовых задач как выполненных (удаление) и автоматический перенос периодических задач на следующую дату.
* **Правила повторения:** поддерживаются базовые правила — ежегодно (`y`) и через заданное количество дней (`d`).

**Задания со звёздочкой:**
*  **Выполнил:** Поиск задач. На главной странице работает фильтрация задач по тексту (поиск по заголовку и комментарию) и по конкретной дате (в формате `DD.MM.YYYY`).
*  **Не выполнил:** Поддержка сложных правил повторения (`w`, `m`), аутентификация по паролю с использованием JWT-токенов и упаковка приложения в Docker-образ.

## Инструкция по запуску локально

1. Убедитесь, что на вашем компьютере установлен язык Go
2. Склонируйте репозиторий и перейдите в папку с проектом.
3. Запустите веб-сервер командой в терминале:
   ```bash
   go run main.go
    ```
## Инструкция по запуску тестов

Перед запуском тестов убедитесь, что конфигурация в файле `tests/settings.go` настроена следующим образом:

```text
Port = 7540
DBFile = "../scheduler.db"
FullNextDate = false  // Сложные правила не реализованы
Search = true         // Поиск по тексту и дате реализован
Token = ""            // Аутентификация не реализована
```
Для запуска всех тестов выполните команду в корневой папке проекта:
```bash
go test ./tests
